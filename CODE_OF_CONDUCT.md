# Código de conducta

Esta red existe para que gente de disciplinas distintas trabaje junta a distancia. Para que eso funcione:

- Trato respetuoso, siempre. Se discuten ideas, no personas. Sin acoso, sin descalificaciones, sin presión para revelar identidad o ubicación.
- Seudónimos bienvenidos en GitHub y Discord. Nadie pide a otra persona que diga dónde está.
- Crédito a quien hace el trabajo. Quien aporta aparece como autor o autora; quien acompaña lo declara con su rol.
- Datos ajenos: no se publican datos personales de terceros, ni información de víctimas sin verificar, ni datos de menores, en ningún canal ni repositorio.
- Lo ajeno se atribuye. Texto, datos, imágenes o código de otras personas se citan con su licencia; si la licencia no lo permite, no se copia.
- Desacuerdos: se resuelven en el issue o en el hilo, con argumentos. Si no se resuelve, lo media la coordinación.
- Reportes: escribe en privado a cualquier persona de la coordinación en Discord o abre un issue en este repositorio con la etiqueta `conducta`. Se responde en menos de una semana y se protege a quien reporta.

La coordinación puede retirar el acceso a quien incumpla estas reglas. Las decisiones se registran.
